# Categories, never literals: a pattern spelling out what it hides would leak
# it. One PCRE per line, `#` comments ignored. Project-private additions go in
# the untracked lints/private-patterns.txt.
#
# A build host's home directory, on any platform someone might build this on.
# /root is deliberately absent: it names no person and is a real path inside
# the container images.
(/home|/Users|/mnt/[a-z]/Users|[A-Za-z]:[\\/]Users)[\\/][^\\/[:space:]"']+
# Any language other than the one this project is written in.
[\x{0400}-\x{04FF}]
